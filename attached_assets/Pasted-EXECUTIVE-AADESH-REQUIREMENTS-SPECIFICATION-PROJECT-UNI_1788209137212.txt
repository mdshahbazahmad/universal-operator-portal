EXECUTIVE AADESH / REQUIREMENTS SPECIFICATION
PROJECT: UNIVERSAL SUPPORTER PORTAL (PHASE 1)
MODULE: LIVE COMPLAINT & TICKETING TRACKER (MAIN SERVER INTEGRATED)

1. OBJECTIVE (Uddeshya)
Customer ki sabhi samasyaon ko real-time main server se jodna, unhe transparent live tracking dena aur missing complaints ko zero karna.

2. FRONTEND FORM: CUSTOMER COMPLAINT FORM
(Yeh Form Customer Portal par Sabse Prominent Place par Rahega)

A. Mandatory Fields (Anivarya Details):
1. User Identification (Auto-fetched from Main Server):
   - Customer ID / Account Number
   - Registered Name & Contact Number
2. Incident Categorization (Dropdown):
   - Priority Level: [ Low / Medium / High / Critical (Emergency) ]
   - Service/Product Category: [ Select Category ]
   - Specific Issue Type: [ Select Sub-Category ]
3. Problem Details:
   - Complaint Subject / Title: [ Short Text ]
   - Detailed Description: [ Text Area ]
   - Upload Supporting Files: [ Drag & Drop (Image, PDF, Logs - Max 25MB) ]

B. Dynamic Actions (On Form Submit):
- Click "Submit Complaint" -> Direct Data Push to Main Server Database.
- System Action: 
  1. Auto-generate Unique Ticket ID (e.g., TKT-2026-89412).
  2. Send instant SMS/Email/WhatsApp confirmation to Customer with direct tracking link.

3. REAL-TIME CUSTOMER LIVE TRACKER BAR
(Har Ticket ke detail page par yeh bar main server se sync hokar chalega)

Visual Progress Bar Steps:
[ Step 1: Ticket Raised ] -> [ Step 2: In Progress / Assigned ] -> [ Step 3: Resolution Underway ] -> [ Step 4: Closed ]

Tracker Data Display (Server Linked):
- Assigned Agent/Engineer Name & ID: [ Live Sync ]
- Estimated SLA Resolution Time: [ Countdown Timer, e.g., 03 Hrs 45 Mins Left ]
- Current Status Badge: [ Open / In-Progress / Pending Parts / Resolved ]

4. INTEGRATION & ACTION CONTROLS (CUSTOMER SIDE)

1. Re-Open Button:
   - Condition: Ticket resolve hone ke 48 ghante tak visible rahega.
   - Action: Agar customer dissatisfied hai, single click par status "Re-Opened" hoke main server par alert trigger karega.
2. Escalation Button (Urgency Trigger):
   - Condition: Agar SLA time limit cross ho jaye aur issue solve na ho.
   - Action: Direct alert goes to Level 2/Level 3 Management Supervisor.
3. Activity Logs / Thread History:
   - Customer aur Agent ke beech hone waali baat-cheet (Chat/Notes) chronological order mein main server par save rahegi.
