Portal Setup & Help Guide (Eagle Network SBZ)


1. साइन-अप और लॉगिन (Sign Up & Login) कैसे करें?

पोर्टल के होम पेज पर जाएँ। अगर आप नए ऑपरेटर हैं तो 'Sign Up' पर क्लिक करके अपना ईमेल, पासवार्ड और कंपनी का नाम दर्ज करें। अकाउंट बनते ही आप डैशबोर्ड में प्रवेश कर जाएंगे।

2. नया ग्राहक (OLT / Router / Box) कैसे जोड़ें?

'Add Customer' बटन पर क्लिक करके पॉप-अप फॉर्म में कनेक्शन का प्रकार (OLT FTTH, Wi-Fi Router, या Set-Top Box) चुनकर नाम, फ़ोन नंबर और सीरियल नंबर दर्ज करके सीधे सेव करें।

3. सर्वर और OLT कैसे कनेक्ट करें?

'Server / OLT Sync' टैब में जाएँ। अपनी कंपनी के Mikrotik या OLT का IP Address और Secret API Token डालें। 'Connect Server' पर क्लिक करते ही आपका पूरा कस्टमर डेटा ऑटो-सिंक हो जाएगा।

4. बल्क डेटा एक्सेल से कैसे अपलोड करें? (1-Click Excel Upload)

'1-Click Excel Upload' बटन पर क्लिक करें और अपनी `.xlsx` या `.csv` फ़ाइल चुनें। फ़ाइल चुनते ही 1 सेकंड में आपके सभी ग्राहकों की लिस्ट यहाँ दिखने लगेगी।
